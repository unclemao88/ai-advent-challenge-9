Ask anything to start a task.

Every task runs as a state machine: idle → planning → execution → validation → done, stopping in waiting_for_user for questions and invariant conflicts. In Manual mode the agent stops after each state; in Auto mode it runs straight through.

  • profile (next to ask) sets the style, format and limitations of every answer.
  • Invariants are hard rules the agent never violates — try the examples, then ask Rewrite backend in Python.
  • remember: … and remember solution: … save to long-term memory; requirement: …, decision: …, fact: … go to the task's work memory.
